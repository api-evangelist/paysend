# Paysend

> Paysend is a London-headquartered global fintech (founded 2017) running a cross-border digital payments network that moves money to bank accounts, cards, and wallets across 170+ countries in 40+ currencies. Paysend Enterprise exposes a single Payout API: one integration disburses funds worldwide to cards and accounts, with FX lookups, bank/card tokenization utilities, partner statements, balance queries, and webhook notifications. The surface is partner-provisioned (enterprise onboarding); no downloadable OpenAPI or public base URL is published.

## API
- [Paysend Enterprise Payout API — Product overview](https://developer.paysend.com/product-overview/): One API for global payout coverage to cards and accounts.
- [API overview](https://developer.paysend.com/api-overview/): Multi-task POST /processing model plus GET /processing/status/.
- [Endpoints](https://developer.paysend.com/category/endpoints): pay.toCard, pay.toAccount, fx.rateGet, fx.rateGet.p2a, bank.get, bank.search, card.createToken, card.infoGet, partner.statementGet, getBalance, task.statusGet.

## Authentication
- [Authentication & idempotency](https://developer.paysend.com/authentication-and-idempotency/): API key + HMAC signature in X-OPP-Signature (SHA-256/512 over {RequestBody}{InboundAPIKey}); idempotency via header.request.id + header.request.date.

## Events
- [Webhook notification service](https://developer.paysend.com/webhook-notification-service/): Configurable callback URLs delivering TransactionStatusUpdate (invoiceId, transactionId, status, statusDateTime, errorCode, errorDescription).

## Statuses & errors
- [Statuses reference](https://developer.paysend.com/statuses/): Request statuses (Accepted/InProgress/Finished), task statuses (Accepted/InProgress/Success/Error), task result codes 0/1/2/3/5.

## Testing
- [Sandbox mock service](https://developer.paysend.com/api-overview/api-sandbox-mock-service/): Static predefined responses; error simulation by setting a function's trigger field to the target error code.
